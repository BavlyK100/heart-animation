# 💖 Heart Animation

An interactive, responsive, and ultra-smooth heart animation built with pure HTML, CSS, and JavaScript.

## ✨ Features

- **Top-to-Bottom Wave Reveal**: The heart emerges row-by-row with spring physics.
- **Synchronized Heartbeat Pulse**: Staggered breathing and glow effects across all hearts.
- **Surprise Finale**: *"I Love You 💖"* bursts from the heart center, floats, and falls with realistic gravity.
- **Confetti Explosion**: Festive colorful confetti shower at the climax.
- **Mobile Interactive (Device Motion)**:
  - 🔄 **Tilt**: Tilts the 3D perspective of the heart based on phone orientation.
  - 📳 **Shake**: Wiggles all hearts in a playful dance.
- **Fully Responsive**: Scales seamlessly on phones, tablets, and desktops using CSS `clamp()`.
- **Zero Dependencies**: Pure HTML/CSS/JS, 60fps hardware-accelerated animations.
